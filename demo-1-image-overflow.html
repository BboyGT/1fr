Demo 01 — The Bug: Image Overflow

A 400px image inside a 1fr column. The column ignores the 500px container and grows to fit the image's intrinsic size instead.

Live Demo

Container is 500px wide. Both columns are 1fr. The image is 400px.

Right column This column should be equal to the left. It's been squeezed into whatever space remains after the image set its minimum.

↑ Red outline = 500px container boundary. Left column has escaped it.

Left column: 400px image sets the track minimum to 400px. 1fr can't go below it.
Right column: gets whatever is left — 100px. Text wraps on almost every word.
/* The grid definition */
.grid {
  display: grid;
  grid-template-columns: 1fr 1fr;
  /* resolves to: minmax(auto, 1fr) minmax(auto, 1fr) */
  /* auto minimum = image's intrinsic width = 400px */
  /* left track minimum: 400px — right track gets the rest */
}

/* The fix */
.grid {
  grid-template-columns: minmax(0, 1fr) minmax(0, 1fr);
  /* minimum floor removed — both columns equal */
}
