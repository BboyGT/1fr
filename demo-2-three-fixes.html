Demo 02 — Three Fixes Side by Side

The same grid. The same image. Three different track definitions. The difference in result is immediate.

❌ Broken — 1fr 1fr

This column should be equal. The image's intrinsic size set a minimum the grid couldn't override.

grid-template-columns: 1fr 1fr; /* resolves to minmax(auto, 1fr) */

✅ Fixed — minmax(0, 1fr) on the track

Minimum floor removed from the track. Both columns are equal. The image scales down to fit.

grid-template-columns: minmax(0, 1fr) minmax(0, 1fr); /* floor removed */

✅ Fixed — min-width: 0 on the item

Same result. The fix lives on the item instead of the track. Useful when you don't control the grid definition.

.grid-item { min-width: 0; } /* item minimum reset */
