A pre block doesn't wrap. Its min-content size is the width of its longest line. That becomes the track minimum — and the grid stretches to match it.

function calculateFreeSpace(containerWidth, tracks) {
  const minimums = tracks.map(t => resolveMinContent(t));
  const totalMin = minimums.reduce((sum, min) => sum + min, 0);
  const freeSpace = containerWidth - totalMin;
  return Math.max(0, freeSpace);
}

Column that should be equal

The pre block's longest line sets the track minimum. The grid stretches the left column to match it, regardless of the container width.

Key takeaway: pre blocks, long URLs, and anything with white-space: nowrap all have large intrinsic minimum sizes. They trigger the same 1fr behaviour as oversized images. The fix is identical — minmax(0, 1fr) on the track.
